Unsupervised Learning - K-Means

K-Means is an unsupervised learning algorithm used to group data into clusters based on similarity.

Project Objective

This project focuses on identifying optimal locations for electric vehicle charging stations in Colombia.

Dataset Variables
  • Current Latitude
  • Current Longitude
  • Traffic Data
  • Charging Load kW
How the Algorithm Works
  • Select the number of clusters
  • Initialize centroids
  • Assign points to the nearest centroid
  • Update centroids iteratively
  • Repeat until convergence
Purpose of the Model

The algorithm helps identify geographic zones with similar charging demand patterns, supporting decision-making for the installation of EV charging stations.
